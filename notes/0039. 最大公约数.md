最大公约数就是两个数“共有的最大因子”。而在算法题里，**欧几里得算法（辗转相除法）** 是求 GCD 的绝对主力，必须熟练掌握。

## 1. 最大公约数

**最大公约数**（Greatest Common Divisor，简称 **GCD**），在数学上指的是：**两个或多个整数共有约数中最大的一个。**

举个简单的例子：

- **12** 的约数有：1, 2, 3, 4, 6, 12
- **18** 的约数有：1, 2, 3, 6, 9, 18
- 它们**公有的**约数是：1, 2, 3, 6
- 其中最大的是 **6**，所以 12 和 18 的最大公约数就是 **6**，记作 $\gcd(12, 18) = 6$。

下面详细讲讲最大公约数的三种计算方法和它的重要性质。

## 2. 计算方法

### 2.1. 质因数分解法（数学基础）

将两个数分别分解质因数，然后取出它们**共有的质因数的最小次幂**相乘。

- $12 = 2^2 \times 3^1$
- $18 = 2^1 \times 3^2$
- 共有的质因数是 2 和 3。取最小次幂：$2^1 \times 3^1 = 6$。

### 2.2. 列举法（适合小数字）

就是像上面那样，把所有约数列出来，找最大的公共项。但对于大数字效率极低。

### 2.3. 欧几里得算法（辗转相除法）

这是编程中最常用的方法：

```js
const gcd = (a, b) => (b === 0 ? a : gcd(b, a % b))
```

**核心原理**：$\gcd(a, b) = \gcd(b, a \bmod b)$

也就是说，**a 和 b 的最大公约数，等于 b 和（a 除以 b 的余数）的最大公约数**。

一直重复这个过程，直到余数为 0，此时的除数就是最大公约数。

**举例演示 $\gcd(18, 12)$：**

- $18 \bmod 12 = 6$，问题变成求 $\gcd(12, 6)$
- $12 \bmod 6 = 0$，问题变成求 $\gcd(6, 0)$
- 当余数为 0 时，另一个数 6 就是最大公约数，结束

## 3. 重要性质

- **裴蜀定理（Bézout's identity）**：对于任意整数 $a$ 和 $b$，存在整数 $x$ 和 $y$，使得 $ax + by = \gcd(a, b)$。
- **与最小公倍数的关系**：$\gcd(a, b) \times \text{lcm}(a, b) = a \times b$（$\text{lcm}$ 是最小公倍数）。
- **互质**：如果 $\gcd(a, b) = 1$，则称 $a$ 和 $b$ 互质（互素）。比如 3 和 5。
- **任何数与 0 的 GCD**：$\gcd(a, 0) = a$。这也是欧几里得算法递归的终止条件（代码中 `b === 0 ? a` 的由来）。

## 4. 在编程中的常见应用

1.  **分数化简**：分子分母同时除以它们的最大公约数，即可得到最简分数。
2.  **水壶问题**：判断目标水量是否能被两个水壶容量的 GCD 整除。
3.  **周期问题**：比如两个齿轮分别有 $a$ 个齿和 $b$ 个齿，它们再次回到初始咬合状态，需要转过的齿数是 $\text{lcm}(a, b)$，可以通过 GCD 快速计算。
4.  **加密算法**：RSA 加密算法的核心之一就是基于大质数和最大公约数的计算（求模逆元）。
