## 1. 题目描述

有两个容量分别为 `x` 升和 `y` 升的水壶，水的供应是无限的。确定是否有可能使用这两个壶准确得到 `target` 升水。

允许的操作：

1. 装满任意一个水壶
2. 清空任意一个水壶
3. 将水从一个水壶倒入另一个水壶，直到接水壶已满，或倒水壶已空。

## 2. 核心数学原理：裴蜀定理（Bézout's identity）

这道题看似是一个模拟倒水过程的搜索问题（可以用 BFS 解决），但利用数学定理，可以将其转化为一个 $O(\log n)$ 的数学判断问题。

### 2.1. 原始定义

对于任意两个不全为零的整数 $a$ 和 $b$，设它们的最大公约数为 $d = \gcd(a, b)$。那么，一定存在整数 $x$ 和 $y$，使得：

$$
ax + by = d
$$

### 2.2. 等价推广（核心结论）

一个整数 $z$ 能通过 $a$ 和 $b$ 加减组合出来，**当且仅当** $z$ 是 $\gcd(a, b)$ 的倍数。

### 2.3. 定理的严谨推导

**（1）正推：任何加减组合出来的数，一定是 $\gcd(a,b)$ 的倍数**

设 $d = \gcd(a, b)$，则 $a = md, b = nd$（$m, n$ 为整数）。

对于任意线性组合 $T = ax + by$，代入得：

$$
T = (md)x + (nd)y = d(mx + ny)
$$

因为 $mx + ny$ 是整数，所以 $T$ 必然是 $d$ 的倍数。

**（2）逆推：$\gcd(a,b)$ 的倍数一定能被组合出来（构造性证明）**

利用**欧几里得算法回代**：

辗转相除的过程为：

- $a = q_1 b + r_1$
- $b = q_2 r_1 + r_2$
- ...
- $r_{k-2} = q_k r_{k-1} + r_k$ （此时 $r_k$ 就是 $\gcd(a,b)$）

从倒数第二步开始回代：$r_k = r_{k-2} - q_k r_{k-1}$

接着把 $r_{k-1}$ 用前两项替换，不断往上回代，最终一定能得到 $r_k = a \cdot x + b \cdot y$ 的形式。

这证明了 $\gcd(a, b)$ 本身一定可以表示为 $a$ 和 $b$ 的线性组合。那么对于它的任意倍数 $z = k \cdot \gcd(a, b)$，只需等式两边同乘 $k$，即可得到 $z = a(kx) + b(ky)$。

## 3. 最大公约数（GCD）与欧几里得算法

### 3.1. GCD 定义

两个或多个整数共有约数中最大的一个。记作 $\gcd(a, b)$。

### 3.2. 欧几里得算法（辗转相除法）

编程中最常用的求 GCD 的方法：

```js
const gcd = (a, b) => (b === 0 ? a : gcd(b, a % b))
```

**核心原理**：$\gcd(a, b) = \gcd(b, a \bmod b)$

**严谨证明（集合互为子集）：**

设 $a = qb + r$（即 $r = a \bmod b$），我们要证明 $\gcd(a, b) = \gcd(b, r)$。

- **正向**：设 $d$ 是 $a, b$ 的公约数。因 $d|a, d|b$，所以 $d|(a - qb)$，即 $d|r$。所以 $d$ 也是 $b, r$ 的公约数。
- **反向**：设 $d$ 是 $b, r$ 的公约数。因 $d|b, d|r$，所以 $d|(qb + r)$，即 $d|a$。所以 $d$ 也是 $a, b$ 的公约数。
- **结论**：$a, b$ 的公约数集合与 $b, r$ 的公约数集合完全相等，因此最大公约数必然相同。

## 4. 回到水壶问题：数学建模

1. **操作的本质**：
   - 装满/清空：水量发生加减变化。
   - 倒水：将一个壶的水量转移到另一个壶，本质上也是水量的加减法。
   - 因此，每次操作后，水壶中水量的变化量一定是 $x$ 和 $y$ 的线性组合（$ax + by$）。
2. **充要条件**：
   根据裴蜀定理，能倒出的水量 `target` 必须且只能是 $\gcd(x, y)$ 的倍数。
   即：`target % gcd(x, y) === 0`
3. **边界条件**：
   如果两个水壶总容量 $x + y$ 都小于目标水量 `target`，无论怎么倒，水壶里的水也不可能达到 `target`，直接返回 `false`。

## 5. 代码实现

**JavaScript:**

```js
var canMeasureWater = function (jug1Capacity, jug2Capacity, targetCapacity) {
  // 边界条件：总容量不足
  if (jug1Capacity + jug2Capacity < targetCapacity) return false
  
  const gcd = (a, b) => (b === 0 ? a : gcd(b, a % b))
  
  // 裴蜀定理判断
  return targetCapacity % gcd(jug1Capacity, jug2Capacity) === 0
}
```

**Python:**

```python
class Solution:
    def canMeasureWater(self, jug1Capacity: int, jug2Capacity: int, targetCapacity: int) -> bool:
        if jug1Capacity + jug2Capacity < targetCapacity:
            return False
        return targetCapacity % math.gcd(jug1Capacity, jug2Capacity) == 0
```

## 6. 复杂度分析

- **时间复杂度**：$O(\log(\min(x, y)))$。这是欧几里得算法求最大公约数的时间复杂度。
- **空间复杂度**：$O(\log(\min(x, y)))$。递归调用栈的深度，与欧几里得算法的递归次数成正比。

## 7. 总结

水壶问题是**数论与实际算法结合**的经典案例。它将模拟倒水的搜索问题（BFS/DFS）降维打击为一次简单的 GCD 求余运算，完美体现了数学在算法优化中的巨大威力。

> **💡 易错点提醒**：
> 1. 笔记中的定理名称为**裴蜀定理**（Étienne Bézout），容易误写为“裴蕴定理”（隋朝历史人物），需要注意。
> 2. 在使用辗转相除法证明逆命题时，务必注意证明的**双向包含**，避免逻辑不严谨。
> 3. 不要忘记边界条件 `x + y < target` 的拦截。
