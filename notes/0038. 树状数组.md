## 1. 它解决什么问题

维护一个数组，支持两种操作：

- **单点修改**：修改某个位置的元素。
- **前缀和查询**：求前 i 个元素的和。

用普通数组：

- 修改 O(1)，查询 O(n)

用前缀和数组：

- 修改 O(n)，查询 O(1)

树状数组让两者都做到 **O(log n)**。

## 2. 核心思想

树状数组用一个辅助数组 `tree` 维护原数组若干段区间的和。

约定：

- 原数组下标从 0 开始。
- `tree` 下标从 1 开始，`tree[i]` 对应原数组下标 `i - 1`。
- `tree[i]` 管理的原数组区间是 `[i - lowbit(i), i - 1]`。

其中 `lowbit(i) = i & -i`，表示 i 的二进制中最低位的 1 及其后面的 0 组成的数。

例：

| i | 二进制 | lowbit(i) | tree[i] 管原数组下标 |
|---|---|---|---|
| 1 | 1 | 1 | [0, 0] |
| 2 | 10 | 2 | [0, 1] |
| 3 | 11 | 1 | [2, 2] |
| 4 | 100 | 4 | [0, 3] |
| 5 | 101 | 1 | [4, 4] |
| 6 | 110 | 2 | [4, 5] |
| 7 | 111 | 1 | [6, 6] |
| 8 | 1000 | 8 | [0, 7] |

每个 `tree[i]` 覆盖的区间长度恰好是 `lowbit(i)`，右端点恰好是 `i - 1`。

## 3. 两个核心操作

### 3.1. 查询前缀和 `query(i)`

求原数组前 i 个元素的和（下标 0 到 i-1）。

```js
function query(i) {
  let s = 0;
  while (i > 0) {
    s += tree[i];
    i -= i & -i;
  }
  return s;
}
```

思路：从 i 开始，每次减去 `lowbit(i)`，把前缀拆成若干个互不重叠的区间累加。

例：`query(6)`

- `tree[6]` 管 `[4,5]`
- `i = 6 - 2 = 4`，`tree[4]` 管 `[0,3]`
- `i = 4 - 4 = 0`，结束

合起来 `[0,5]`，不重不漏。

### 3.2. 单点更新 `update(index, delta)`

把原数组下标 `index` 的值增加 `delta`。

```js
function update(index, delta) {
  let i = index + 1;
  while (i <= n) {
    tree[i] += delta;
    i += i & -i;
  }
}
```

思路：从 `index + 1` 开始，每次加上 `lowbit(i)`，向上更新所有覆盖该位置的节点。

例：更新原下标 2

- `i = 3`，更新 `tree[3]`
- `i = 3 + 1 = 4`，更新 `tree[4]`
- `i = 4 + 4 = 8`，更新 `tree[8]`
- ……

这些节点都包含原下标 2。

## 4. 区间和

区间 `[l, r]` 的和：

```js
query(r + 1) - query(l)
```

用两个前缀和相减即可。

## 5. 为什么 lowbit 能保证正确

- **更新时 `i += i & -i`**：跳到的每个节点都包含起始位置。因为 `tree[i]` 覆盖 `[i - lowbit(i), i - 1]`，而 `i + lowbit(i)` 是下一个覆盖该位置的节点。
- **查询时 `i -= i & -i`**：选出的区间互不重叠，且拼起来恰好是 `[0, i - 1]`。因为每次减去的 `lowbit` 正好是当前节点覆盖的区间长度。

两个方向的步长都是 `lowbit`，但一个加一个减，所以更新是“向上覆盖”，查询是“向下拆解”。

## 6. 复杂度

| 操作 | 时间复杂度 | 空间复杂度 |
|---|---|---|
| 初始化 | O(n log n) | O(n) |
| 单点更新 | O(log n) | O(1) |
| 前缀和查询 | O(log n) | O(1) |
| 区间和查询 | O(log n) | O(1) |

n 次操作总复杂度 O(n log n)。

## 7. 初始化

从全 0 开始，依次对每个位置执行 `update(i, nums[i])`，时间复杂度 O(n log n)。

也可以 O(n) 建树：

```js
for (let i = 1; i <= n; i++) {
  tree[i] += nums[i - 1];
  const j = i + (i & -i);
  if (j <= n) tree[j] += tree[i];
}
```

原理：每个节点在累加完自己后，把值贡献给它的父节点。

## 8. 适用场景

树状数组适合：

- 单点修改 + 前缀和 / 区间和
- 动态维护频次并查询排名
- 求逆序对
- 二维偏序
- 区间计数

它比线段树代码短、常数小，但不支持区间修改 + 区间查询（除非配合差分或额外技巧）。

## 9. 一句话总结

树状数组用 `lowbit` 把前缀和拆成若干互不重叠的区间，把单点更新的影响向上传播到所有包含它的区间，从而让修改和查询都达到 O(log n)。
